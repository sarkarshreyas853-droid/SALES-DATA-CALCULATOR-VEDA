# Task 4: Sales Data Calculator

## Aim
Understand basic numerical data analysis using Python.

## What the notebook does
- Stores a manually created list of 10 sales values.
- Calculates the total sales, average sale, highest sale and lowest sale using built-in Python functions.
- Checks each result against the original data.
- Explains the results and answers the three interview questions.

## Results
| Measure | Value |
|---|---|
| Total sales | 136,000 |
| Average sale | 13,600.00 |
| Highest sale | 22,100 |
| Lowest sale | 7,600 |
